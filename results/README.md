# Verified Results

This directory contains the computed results for the Top 10 Campaigns by CPA and CTR, generated by the `campaign` application.

## Files

- **`top_10_cpa.csv`**: Top 10 campaigns with the lowest Cost Per Action (CPA).
- **`top_10_ctr.csv`**: Top 10 campaigns with the highest Click-Through Rate (CTR).
- **`top_10_cpa_postgres.csv`**: Reference results computed directly via PostgreSQL for verification.
- **`top_10_ctr_postgres.csv`**: Reference results computed directly via PostgreSQL for verification.

## PostgreSQL Verification

To verify the accuracy of the application's output, you can import the raw CSV dataset into PostgreSQL and run standard aggregation queries.

### 1. Import Data

First, create the table schema and import the data (adjust the path to `ad_data.csv` as needed):

```sql
create table ad_data
(
    campaign_id text,
    date        text,
    impressions numeric,
    clicks      numeric,
    spend       numeric,
    conversions numeric
);

\copy ad_data FROM '../data/ad_data.csv' DELIMITER ',' CSV HEADER;
```

### 2. Verify CPA (Low to High)

Run this query to find the top 10 campaigns with the lowest CPA:

```sql
SELECT
    campaign_id,
    SUM(impressions)                                              AS total_impressions,
    SUM(clicks)                                                   AS total_clicks,
    ROUND(SUM(spend)::numeric, 4)                                 AS total_spend,
    SUM(conversions)                                              AS total_conversions,
    ROUND((SUM(clicks)::numeric / NULLIF(SUM(impressions), 0)), 6) AS ctr,
    ROUND((SUM(spend)::numeric  / NULLIF(SUM(conversions), 0)), 4) AS cpa
FROM ad_data
GROUP BY campaign_id
ORDER BY (SUM(spend)::numeric  / NULLIF(SUM(conversions), 0))
LIMIT 10;
```

### 3. Verify CTR (High to Low)

Run this query to find the top 10 campaigns with the highest CTR:

```sql
SELECT
    campaign_id,
    SUM(impressions)                                              AS total_impressions,
    SUM(clicks)                                                   AS total_clicks,
    ROUND(SUM(spend)::numeric, 4)                                 AS total_spend,
    SUM(conversions)                                              AS total_conversions,
    ROUND((SUM(clicks)::numeric / NULLIF(SUM(impressions), 0)), 6) AS ctr,
    ROUND((SUM(spend)::numeric  / NULLIF(SUM(conversions), 0)), 4) AS cpa
FROM ad_data
GROUP BY campaign_id
ORDER BY (SUM(clicks)::numeric / NULLIF(SUM(impressions), 0)) DESC
LIMIT 10;
```
